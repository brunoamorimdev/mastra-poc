# Mastra AI POC

## Minimal Viable Product

- Create a Mastra AI integrated workflow that executes the following flow:
  1. Create a branch in a github repo
  2. Edit code
  3. Commit changes
  4. Generate the Pull Request
- The developer's prompt must be this: "You are a Senior Typescript Developer specialized in developing scalable applications using TDD, clean arch and BDD"
- Use `.env` to store secrets and a `constants.ts` to allow dynamic configuration.
